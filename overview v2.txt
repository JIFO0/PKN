Overview

The Science Communities Platform is implemented as a WordPress plugin that provides a centralized catalog and search engine for academic science communities.
The platform focuses on discoverability, archival transparency, and administrative monitoring, rather than acting as a full standalone social platform.

1. The plugin enables users to:
- Browse and search all science communities
- Filter communities by tags, specialization and operational status
- View detailed public profiles of each community

2. The plugin enables science community owners to:
- Add/edit info about their science community
- Send an mail to every person following this science community

3. At the same time, platform administrators (superadmins) are responsible for:
- Monitoring whether communities are still active
- Updating their operational status
- Maintaining an accurate and verified archive of inactive or suspended communities

Each science community is assigned a random 5-letter public ID, which is used internally for identification, permissions, and future admin tooling.
Core Functionalities:
- Public-facing features
- Search engine that searches community name and short description
- Advanced filtering (status, 2-16 tags, descriptions)
- Paginated search results displayed sequentially
- Admin panel for superadmins and panel for science community admins

Public detail page for each community, including:
- Name
- Short description
- Full description
- Logo
- Website and social media links
- Current operational status
- Administrative features
- Centralized admin panel (outside of WordPress admin)
- Manual verification of community activity
- Status management and archival marking
- Edit access restricted by internal permission logic (to be expanded later)
- Prepared infrastructure for future CSV / Excel imports
